# Issue tracker: GitHub

Issues and specs for this repository live in GitHub Issues for `sevenR8/DailyAccounting_App`. Use the connected GitHub integration, always specifying that repository.

## Conventions

- **Create an issue**: create it in `sevenR8/DailyAccounting_App` with a title, Markdown body, and required labels.
- **Read an issue**: fetch the issue and its labels from `sevenR8/DailyAccounting_App`.
- **List issues**: list open issues in `sevenR8/DailyAccounting_App` with suitable label filters.
- **Comment on an issue**: add a comment to the issue in `sevenR8/DailyAccounting_App`.
- **Apply or remove labels**: update the issue labels in `sevenR8/DailyAccounting_App`.
- **Close an issue**: close the issue in `sevenR8/DailyAccounting_App` with an explanatory comment.

## Pull requests as a triage surface

**PRs as a request surface: no.**

## When a skill says "publish to the issue tracker"

Create a GitHub issue in `sevenR8/DailyAccounting_App`.

## When a skill says "fetch the relevant ticket"

Fetch issue `<number>` from `sevenR8/DailyAccounting_App`, including comments and labels.
