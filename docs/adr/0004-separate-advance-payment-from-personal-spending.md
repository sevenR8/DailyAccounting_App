# 代墊保留實際付款與個人負擔兩種金額

代墊開銷保留實際支付總額供現金與信用卡帳單核對。消費分析與總開銷不預先假設待收款一定能收回：尚未收回時保留完整支出，部分收回時只扣實收金額，全額收回後才呈現最終的個人負擔。代墊收回獨立於收入，因為將實際付款直接改小會使帳單無法對帳，將收回款當成收入則會虛增本期收入。

摘要中的信用卡保留完整刷卡額；現金主要金額則顯示實付現金扣除本期代墊收回後的淨現金流，並在明細保留實付與收回數值。本期可存額使用相同淨現金流，因此信用卡代墊收回也會增加當期可用現金，但不增加收入。

每日紀錄的「總開銷」使用原始實付扣除已實際收回代墊款後的個人負擔加總；同列的現金與信用卡仍保留原始實付金額，供付款方式核對。
